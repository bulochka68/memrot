## Коротко

- **Кто пользователь:** инженер, выпускающий агента с памятью и инструментами в прод.
- **Какую проблему решаем:** однохододовые сканеры не видят атаку, которая проявляется
  в другой сессии или у другого пользователя — а именно она и есть реальный риск агента с памятью.
- **Что сделали:** статический аудит по 28 контролям + харнесс атак на 77 вариантов,
  связанные общим словарём; аудит задаёт приоритет атаки, атака повышает статус находки.
- **Главное продуктовое решение:** отказ от единого «процента безопасности» в пользу
  честного знаменателя — это решение переписало схему отчёта и определило архитектуру.
- **Что не подтвердилось:** 5 из 10 гипотез, включая нашу собственную ставку на security score.
- **Что не проверено:** ценность в единицах времени до решения о релизе — первый шаг пилота.

```bash
python -m mcp_audit audit examples/genai_invest_stand.manifest.json --json .audit/stand.json

```
